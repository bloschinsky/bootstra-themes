What is gunmetal os?

Gunmetal OS is a Bootstrap 5 theme for building sites that feel like a 2001 Flash desktop: steel windows, floppy-disk icons, pixel type and one glowing colour you can change at any time.

Everything is plain HTML with gm- classes on top of stock Bootstrap. Grid, modals, dropdowns and forms keep working as usual.

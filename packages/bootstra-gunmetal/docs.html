Getting started

Introduction #

Gunmetal OS is a theme for Bootstrap 5.3 that makes pages look like a Flash-era desktop: bevelled steel windows, floppy-disk icons, pixel type and one glow colour that drives every accent. It does not replace Bootstrap. The grid, utilities and JavaScript plugins work as usual; the theme restyles them and adds a small set of gm- classes for the desktop shell.

This page lists every element with a live example and the markup that produces it. To see the pieces assembled into a full site, open the prototype.

Install #

Load the two pixel fonts, Bootstrap, then gunmetal.css. Put gm-os on the body. Add gunmetal.js after the Bootstrap bundle if you want glow switching, draggable windows, wallpapers and the music panel.

<!doctype html>
<html lang="en" data-gm-accent="orange">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <link href="https://fonts.googleapis.com/css2?family=Silkscreen:wght@400;700&family=Saira+Condensed:wght@800&display=swap" rel="stylesheet">
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
  <link href="gunmetal.css" rel="stylesheet">
</head>
<body class="gm-os">
  ...
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
  <script src="gunmetal.js"></script>
</body>
</html>
The theme is dark only and sets color-scheme: dark. Do not add data-bs-theme="dark"; the gm tokens already cover it.

Glow colours #

One accent colour, the glow, is used for plates, icons, LEDs, progress bars, active states, scrollbars and focus. Set a preset on the html element, or pass any hex value through JavaScript. Status colours (success, warning, danger, info) stay fixed so meaning never depends on the glow.

<html data-gm-accent="cyan">

GM.setAccent('lime');      // preset
GM.setAccent('#ff2266');   // any hex

JavaScript API #

gunmetal.js has no dependencies and works through data attributes. Every choice is saved in localStorage and restored on the next visit. The same functions are exposed on window.GM.

Attribute or callWhat it does
data-gm-accent-set="cyan"Switches the glow to a preset on click.
data-gm-accent-customOn an input type="color", applies the picked colour.
data-gm-wall-set="night"Sets the wallpaper on .gm-viewport.
data-gm-target="#id"On an icon, shows that section and hides others with the same data-gm-group. Updates the window title from data-gm-title and data-gm-sub.
data-gm-closeCollapses the nearest window or module to its title strip.
data-gm-resetMoves the nearest window back to where it started. data-gm-reset="all" also restores all settings.
data-gm-track="0"Plays one of nine built-in chip tracks (0–8).
data-gm-action="…"music-toggle, music-off, glow-cycle, wall-cycle, wall-load, text-toggle, shutdown.
.gm-draggableWindows inside it can be dragged by their bar on screens 992px and wider.
GM.setAccent(v) GM.setWall(v) GM.setText(v) GM.setFx(bool) GM.play(i) GM.stop()The same actions from your own code. The gm:accent event fires on document when the glow changes.

Shell

Desktop #

The desktop is three nested layers: .gm-desktop pads the page, .gm-screen is the steel frame with cut corners, and .gm-viewport holds the wallpaper, grain and scanlines. Inside it, .gm-workspace is a two-column grid: the .gm-stage for windows and a 190px .gm-dock on the right. Below 992px the grid becomes one column.

<div class="gm-desktop">
  <div class="gm-screen">
    <div class="gm-viewport gm-wall-sunrise">
      <a class="gm-logo" href="#">
        <span class="gm-logo-word">Gunmetal</span><span class="gm-logo-mark">OS</span>
      </a>
      <div class="gm-workspace gm-draggable">
        <main class="gm-stage"> windows </main>
        <aside class="gm-dock"> modules </aside>
      </div>
      <div class="gm-statusbar">...</div>
    </div>
  </div>
</div>

For a page without the dock, such as this one, use .gm-logo-inline inside a sticky .gm-topbar.

Window #

A window has a bar (grip, reset and collapse), a title box and a grooved body. Put panes inside the body to split content into framed blocks. Add .gm-window-float to make a smaller window that overlaps the one above it, like a palette.

Tags #

Small labels that name a pane or a panel. Place one at the top of a pane, before its content.

Media frame #

.gm-media frames an image or video and turns it into a glow duotone: the picture is made greyscale and multiplied over the glow colour, so photos follow the theme. Add .gm-media-raw to keep original colours.

Components

Buttons #

Standard Bootstrap button classes. Buttons are raised steel and press in when clicked. .btn-primary uses the glow; .btn-dark is a dark key with glowing text; outline variants all use the glow.

Sizes and states

Button group #

Group buttons, or use .btn-check radios for a toggle where one option stays pressed.

Micro controls #

Tiny controls for window bars and dock modules. .gm-chip is a 10px button, .gm-x a square close or collapse button, .gm-key a flat dark key (add .is-on to light it), .gm-grip the striped drag handle and .gm-led a status light.

Extras

Wallpapers #

Six wallpapers are built from CSS gradients, so they need no image files. Apply one as a class on .gm-viewport, or switch at runtime with data-gm-wall-set. The night wallpaper uses the glow for its grid.

Music panel #

Nine looping chip tracks generated with the Web Audio API, so there are no audio files. Any element with data-gm-track plays a track; data-gm-music-readout, data-gm-music-pos and .gm-vu update while it plays.
